# Critical Issues Found in Codebase Review

## 🔴 CRITICAL - Fix Immediately

### 1. ThreadPoolExecutor Resource Leak (eac.py:75)
- Executor created but may not shutdown on crashes
- Fix: Add shutdown in signal handlers and exception paths

### 2. Pose Caching Dead Code (inference_pipeline.py:582-585)
- Dead code block that does nothing (pass statement)
- Fix: Remove or implement intended logic

### 3. Hash Collision Risk (inference_pipeline.py:577,603,615)
- Using Python hash() on crop bytes can collide
- Fix: Use hashlib.md5 or compare actual pose change

### 7. ThreadPoolExecutor Not Shut Down (parallel_processor.py:34)
